# Portifolio Code
Código de Criação do meu Portifólio
Esse é um projeto de um código base para a Criação de um Portifólio online usando HTML e CSS.
Nele observamos espaço de foto de perfil e apresentação, um espaço "sobre mim", a aba de projetos — na qual é possível asicionar imagem ilustrativa, nome e descrição do projeto. E eles serão organizados em boxes individuais. E, por fim, a aba de Contato, por meio da qual aquele que visualiza o portifólio poderá encontrar as redes de contato do profissional.
